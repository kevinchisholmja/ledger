## Terminology cleanup + Bank Accounts (2026-05-25 evening)

### What was changed

**`app/budgets/BudgetsClient.tsx`**:
- "Categories" tab renamed → **"Labels"** (these are expense-tagging labels, not budget groups)
- Group field in budget form renamed → **"Category"** (YNAB terminology: Bills / Needs / Wants)
- Added **Label dropdown** to budget create form — user selects from existing labels (optional)
- All in-form copy updated: "No categories" → "No labels", "Add category" → "Add label", etc.

**`app/plan/PlanClient.tsx`**:
- "+ Add" footer link → **"+ Add Category"**
- "By Group" heading in right summary panel → **"By Category"**

**`app/accounts/AccountsClient.tsx`** (NEW) — client component for bank account management:
- Lists existing bank accounts with name, type, currency, balance
- Net balance header (credit balances subtracted)
- Add Account form: name, type (checking/savings/credit/cash), starting balance, currency
- Delete account with confirm prompt

**`app/accounts/page.tsx`** — redesigned:
- Bank Accounts section at top (via AccountsClient)
- Transactions section below (existing, with "Category" column renamed → **"Label"**)
- Cleaner layout with section headers

**`app/api/accounts/route.ts`** + **`app/api/accounts/[id]/route.ts`** (NEW):
- `GET /api/accounts` — list user's bank accounts
- `POST /api/accounts` — create account
- `PATCH /api/accounts/:id` — update (name/type/balance/currency/active)
- `DELETE /api/accounts/:id` — delete

**`supabase/migrations/20240010_categories_and_bank_accounts.sql`**:
- `ALTER TABLE public.categories ALTER COLUMN bucket_id DROP NOT NULL` — fixes category creation bug
- `CREATE TABLE IF NOT EXISTS public.bank_accounts` — new table for bank account tracking

**`lib/db/schema.ts`** — added `bankAccounts` table + `BankAccount`/`NewBankAccount` types.

### Key terminology decisions
| Old label | New label | Rationale |
|---|---|---|
| "Group" (Plan/Budgets) | "Category" | YNAB: Bills/Needs/Wants are Categories |
| "Categories" tab (Budgets) | "Labels" | These tag transactions, not budget buckets |
| "Category" column (Accounts) | "Label" | Consistent with above |

DB column `group_name` on `buckets` table is unchanged — UI labels differ from DB names.
