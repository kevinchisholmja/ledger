## Web receipt upload (floating button)

### What was built

**`app/api/upload/route.ts`** (NEW):
- `POST /api/upload` — accepts multipart form with a `file` field.
- Auth via `requireUser()` (session-based — no secret key needed).
- Same pipeline as the iOS Shortcut endpoint: upload to Supabase Storage → run OCR → insert expense.
- `source: "manual"`, status starts as `pending_ocr`; promoted to `pending_review` if OCR succeeds.

**`app/components/UploadButton.tsx`** (NEW):
- Floating action button fixed to `bottom-6 right-6` on all pages.
- Accepts: `image/jpeg`, `image/png`, `image/heic`, `image/heif`, `image/webp`, `application/pdf`.
- States: idle (blue "Upload receipt"), uploading (spinner + "Processing…"), error (red + message auto-clears after 4 s).
- On success: navigates to `/review` so the user can immediately confirm the extracted data.

**`app/layout.tsx`** — `<UploadButton />` added to root layout body so it appears on every page automatically.

## Mobile bottom navigation

**`app/components/MobileNav.tsx`** (NEW):
- Replaces the ad-hoc mobile nav that was hardcoded in `app/page.tsx`.
- Bottom tab bar (`md:hidden`) with 5 slots: Home, Review (with pending badge), Txns, Plan, More.
- Review badge fetches from `GET /api/review/count` on every route change.
- "More" opens a slide-up drawer with: Goals, All Accounts, Budgets, Categories, Sign out.
- Drawer auto-closes on navigation via `useEffect([pathname])`.
- Safe area handling: `paddingBottom: "env(safe-area-inset-bottom, 0px)"` via inline style (Tailwind v4 has no built-in safe area utilities).
- Tab bar uses explicit `<div className="flex h-14">` to prevent collapse under browser chrome.
- Drawer positioned at `bottom: "calc(3.5rem + env(safe-area-inset-bottom, 0px))"` so it clears the tab bar.
- z-index stack: backdrop 48, drawer 49, tab bar 50, upload button 30.

**`app/api/review/count/route.ts`** (NEW):
- `GET /api/review/count` — returns `{ count: number }` of `pending_review` + `pending_ocr` expenses.

**`app/layout.tsx`** — `<MobileNav />` added alongside `<UploadButton />`.

**`app/page.tsx`** — hardcoded `MobileNavItem` function and bottom nav block removed (now handled by shared layout).
