## Web receipt upload (floating button)

### What was built

**`app/api/upload/route.ts`** (NEW):
- `POST /api/upload` — accepts multipart form with a `file` field.
- Auth via `requireUser()` (session-based — no secret key needed).
- Same pipeline as the iOS Shortcut endpoint: upload to Supabase Storage → run OCR → insert expense.
- `source: "manual"`, status starts as `pending_ocr`; promoted to `pending_review` if OCR succeeds.

**`app/components/UploadButton.tsx`** (NEW):
- Floating action button fixed to `bottom-6 right-6` on all pages.
- Accepts: `image/jpeg`, `image/png`, `image/heic`, `image/heif`, `image/webp`, `application/pdf`.
- States: idle (blue "Upload receipt"), uploading (spinner + "Processing…"), error (red + message auto-clears after 4 s).
- On success: navigates to `/review` so the user can immediately confirm the extracted data.

**`app/layout.tsx`** — `<UploadButton />` added to root layout body so it appears on every page automatically.
