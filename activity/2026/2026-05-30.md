    draggable gesture handle.

## Phase A7b — Filterable & Sorting Register

### RegisterClient changes (`app/register/RegisterClient.tsx`)
- **Filter bar:** text input for free-text search; dropdown selectors for
  Account, Category, Budget, and Cleared/Reconciled status; all filtering runs
  on the client — no extra server round-trips.
- **Column sorting:** clicking any column header toggles `asc` / `desc` order;
  `▲` / `▼` indicator on the active column; sortable on date, payee, category,
  budget, amount, and running balance.
- **Mobile card view:** table hidden on small viewports; replaced with a vertical
  stack of transaction summary cards; tapping a card expands it to show notes,
  invoice date, source, and quick-action buttons (Flag, Clear, Reconcile).
