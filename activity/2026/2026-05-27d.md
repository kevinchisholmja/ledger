# 2026-05-27d — Phase A5b + Phase A6

## Phase A5b — Flag/Reconcile, TBB Plan, Per-Account Register, OCR Type Detection

### Budget assignments + TBB plan
- `POST /api/budget-assignments` — upserts a monthly envelope allocation for a
  given bucket+month; validates bucket ownership before writing
- `POST /api/budget-assignments/copy-last-month` — copies all prior-month
  assignments to the target month, skipping any already assigned
- `app/plan/page.tsx` rewritten — five parallel queries: buckets,
  budget_assignments for current month, debit spending, income total, pending count
- TBB = income received this month − total assigned this month
- `app/plan/PlanClient.tsx` rewritten — TBB banner (green/red), inline assignment
  editing via budget_assignments upsert (not buckets.amount), "Return to TBB"
  button per envelope, "Move money" modal between envelopes, "Copy last month"

### Per-account register
- `app/accounts/[id]/page.tsx` — filters RegisterClient to a single account;
  breadcrumb shows All Accounts / {name}; 404s if account doesn't belong to user
- `app/accounts/AccountsClient.tsx` — each account row gains a "Register →" link

### Flag and reconciliation workflow
- `app/register/RegisterClient.tsx` — flagged rows get amber background + ⚑ icon;
  expanded row gains Flag/Unflag, Clear/Unclear, Reconcile action buttons;
  Clr column: R / C / ○
- `app/components/TransactionModal.tsx` — flag toggle button added to edit form
- `app/transactions/page.tsx`, `app/accounts/page.tsx`, `app/register/page.tsx`
  — `flagged` and `reconciled` fields added to select queries

### OCR type detection
- `lib/ocr.ts` — `OcrResult` gains `type` field (purchase | income | refund |
  chargeback | bank_fee); prompt instructs Claude to classify the document
- `app/api/upload/route.ts`, `app/api/shortcut/upload/route.ts`,
  `app/api/telegram/webhook/route.ts` — derive `type` and `direction` from
  `ocrResult.type` instead of hardcoding purchase/debit
