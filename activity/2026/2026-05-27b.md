## Phase A4 — Full Rewrite: expenses → transactions

Rewrote all application code to read/write from the v2 `transactions` table.
No functional change visible to the user — all pages and flows work identically.

### Migration applied
**`supabase/migrations/20240014_make_transactions_amount_account_nullable.sql`**
```sql
ALTER TABLE transactions ALTER COLUMN amount DROP NOT NULL;
ALTER TABLE transactions ALTER COLUMN account_id DROP NOT NULL;
```
Required because OCR uploads don't know the amount (OCR may fail → `pending_ocr`)
and account assignment happens later in the review flow. Account assignment via the
Unassigned sentinel is deferred to Phase A5.

### Key field mapping (v1 → v2)
| Old (`expenses`) | New (`transactions`) |
|---|---|
| `merchant` | `payee_name` |
| `raw_ocr_text` | `memo` (Telegram text-only messages) |
| `confirmed_category` (text) | dropped — `category_id` FK is authoritative |
| `ai_suggested_category` | dropped — OCR writes to `category_id` directly |
| `expense_source` enum | `source text` |
| `expense_status` enum | `status text` |
