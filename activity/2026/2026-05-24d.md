## [note] Cursor editor — line numbers setting

User reported line numbers not visible in the editor. Identified that the user
runs Cursor (not VS Code) — both are installed but have separate config directories:

- VS Code: `~/Library/Application Support/Code/User/settings.json`
- Cursor: `~/Library/Application Support/Cursor/User/settings.json`

The initial change went to the VS Code config. Added `"editor.lineNumbers": "on"`
to the Cursor config as well.
